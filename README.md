# Project Repository

##nextStep

nextStep is an app that helps elderly people navigate their phones whenever they get stuck. Apps change constantly and menus, buttons and gestures move around with every update. nextstep notices when a user is struggling and visually points them to the exact thing they need to tap. 

For example, if someone can't figure out how to make a Youtube video full screen, nextStep highlihgts the full-screen button so they can finish the task themselves. 

nextStep works somewhat like a browser extension. It will use AI to detect when a use has been stuck on a screen for too long, then offers help right on that screen. Over time it learns from each users's history, so its guidance gets more personal and more accurate for the apps that person actually uses. 

##The Product Vision Statement 
This app is for older adults who struggle to keep up with constantly changing apps and phone intercase. nextStep is an AI-powered on-screen assistant that detects when they're stuck and highlight exactly what to tap next. Unlike video tutorials, help-center articles or asking a family member for help, nextStep gives real time in-context guidance that learns from each users's habits, so they can stay. independent and confident with their devices. 

##Project History 
nextStep was inspired from previous experiences with watching older folk struggle to keep up with the ever-changing landscapes of apps. Features moves, buttons were redesigned, and simple tasks became frustrating. We realize that many older adults dont need a ful lesson, just a nudge towards the next step. That idea grew into nextStep.
