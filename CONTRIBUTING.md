##Git workflow
Use Standard Git staging and push.
One line of message for push.

1. Pull most recent repo
2. Make a new branch for new task
3. Push the branch to GitHub
4. Create pull request to merge changes to Master branch
5. Request a review from at least one member through Discord
6. Merge the branch after approval
